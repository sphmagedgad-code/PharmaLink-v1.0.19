# PharmaLink OS - Android Live

Android companion layer for PharmaLink OS.

Build:
- Android project: `android/`
- Gradle: 8.7
- Android Gradle Plugin: 8.5.2
- Kotlin: 2.0.21
- Compile/Target SDK: 35
- Java: 17

GitHub Actions builds a debug APK and uploads it as `PharmaLink-APK`.

This package keeps the existing PharmaLink web assets and Android live WhatsApp listener.
